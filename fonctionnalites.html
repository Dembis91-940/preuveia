La méthode de score

Comment PreuveIA calcule votre score /100

Le score combine 4 indicateurs stylistiques locaux, croisés en production avec des API de détection IA. Chaque indicateur est documenté dans le rapport PDF.

📊

Variété des phrases

Un humain alterne phrases courtes et longues, hésite, ponctue. Un texte généré est souvent d'une régularité mécanique. Mesure : écart-type des longueurs de phrases.

📚

Richesse du vocabulaire

Ratio de mots uniques sur les mots de contenu, hors mots-outils. Les textes générés tournent en boucle sur un vocabulaire restreint.

🚩

Absence de marqueurs IA

Plus de 40 formules typiques de génération automatique en français (« en conclusion », « dans le monde d'aujourd'hui », « il est essentiel de »…) sont comptées.

🔁

Peu de répétitions

Fréquence des mots de contenu répétés au-delà de l'usage naturel. La répétition est la signature la plus fiable de la génération automatique.

🗣️

Vivacité (bonus)

Questions rhétoriques, exclamations, adresse directe au lecteur : des marqueurs de voix personnelle qui augmentent le score.

🤖

API de détection (production)

En production, le score local (60 %) est croisé avec des API de détection IA (40 %) : GPTZero, Copyleaks ou classifieur maison, via api.preuveia.fr.
