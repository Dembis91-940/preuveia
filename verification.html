✕

Badge non reconnu

Le code saisi ne correspond pas à un badge PreuveIA valide : format incorrect, checksum invalide ou code altéré.

Vérifiez le code sur le badge du créateur, puis réessayez.

Comment fonctionne la vérification : le code PIA suit un format strict (alphabet sans ambiguïté) et porte un checksum de 4 caractères dérivé des 8 premiers. Toute modification d'un caractère produit un checksum différent → le badge est rejeté. En production, la vérification s'appuie aussi sur un registre central des badges émis.
