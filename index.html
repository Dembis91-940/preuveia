FAQ

Questions fréquentes

PreuveIA détecte-t-il vraiment l'IA ?
Le scan combine une analyse stylistique locale (variété des phrases, richesse du vocabulaire, marqueurs typiques de génération, répétitions) et, en production, des API de détection IA reconnues (GPTZero, Copyleaks, classifieur maison) via notre API. Cette version de démonstration exécute l'analyse localement : l'appel API est simulé et clairement indiqué.
Que garantit le badge « Authenticité vérifiée » ?
Le badge atteste que le contenu scanné a obtenu un score d'authenticité supérieur au seuil défini, à une date donnée, avec un code unique vérifiable publiquement. Il ne garantit pas la qualité pédagogique — il prouve que le contenu n'est pas du remplissage généré automatiquement.
Mes contenus sont-ils utilisés pour entraîner des modèles ?
Non, jamais. Vos contenus servent uniquement à produire votre rapport, ne sont pas revendus et peuvent être supprimés automatiquement après analyse (option disponible dans les réglages).
Puis-je afficher le badge sur n'importe quelle plateforme ?
Oui. Le badge est un snippet HTML/SVG autonome : Teachable, Gumroad, WordPress, Shopify, page Notion ou site sur mesure. Le lien de vérification fonctionne partout.
Que se passe-t-il si quelqu'un copie mon badge ?
Le code unique est vérifié côté public : une copie du visuel sans code valide (ou avec un code modifié) affiche « Badge non reconnu ». En production, la vérification s'appuie sur un registre central des badges.
Puis-je résilier à tout moment ?
Oui, en un clic depuis votre espace membre. Vos rapports déjà générés restent téléchargeables pendant 30 jours.
