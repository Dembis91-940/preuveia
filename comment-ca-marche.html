Accueil / Comment ça marche

De votre transcription au badge vérifiable, en 4 étapes

Le parcours complet, de la soumission du contenu à l'affichage de la preuve sur votre page de vente.

Collez votre contenu

Sur la page de scan, collez votre transcription ou déposez un fichier (.txt, .md, .srt, .vtt, .csv). Minimum 200 caractères — une vraie analyse demande un échantillon significatif.

L'analyse s'exécute

4 indicateurs stylistiques sont calculés localement (variété des phrases, richesse du vocabulaire, marqueurs IA, répétitions) avec un bonus de vivacité. En production, le résultat est croisé avec des API de détection IA via api.preuveia.fr (60 % local / 40 % API).

Recevez le rapport PDF

Score /100, verdict, détail des 4 indicateurs, code unique du badge, date du scan. Le PDF se télécharge en un clic et peut être joint à votre page de vente.

Affichez le badge

Le générateur de badge produit un snippet HTML/SVG à coller sur Teachable, Gumroad, WordPress ou votre site. Chaque badge porte un code unique vérifiable publiquement sur verification.html.

Côté acheteur

Ce que voit votre prospect

Le parcours de vérification est pensé pour durer moins de 10 secondes — pas de compte, pas d'inscription.

Il clique sur le badge

Le badge est un lien : il ouvre la page publique de vérification avec le code unique intégré.

Il voit le verdict

« Authenticité vérifiée » avec la date du scan et le score. Un code modifié affiche « Badge non reconnu ».
